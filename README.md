# Teste Web Renner

Projeto de automação de testes web utilizando **Playwright** e **Cucumber (BDD)**.

## Tecnologias

* JavaScript
* Playwright
* Cucumber (BDD)
* Page Object Model

## Cenário testado

* Busca de dois produtos
* Seleção de tamanho
* Adição ao carrinho
* Validação dos produtos e preços
